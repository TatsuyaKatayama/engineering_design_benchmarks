# Precision Arm Benchmark 評価運用パッケージ

評価運用者向けの評価運用領域です。

## 内容

- `armbench_eval/`: レポート評価器
- `docs/evaluation_guide.md`: 採点観点と運用説明
- `knowledge/hidden_oracle.json`: 評価運用専用の期待観点
- `reports/`: 評価用DOE確認結果
- `scripts/generate_doe_report.py`: DOE確認結果生成
